Node.js Streams Cheat Sheet

Streams process data piece by piece instead of loading it all into memory. A 4 GB log file can be read with a few kilobytes of RAM.

The four stream types

TypeDirectionExample
Readablesource of datafs.createReadStream()
Writabledestinationfs.createWriteStream(), res in HTTP
Duplexboth, independentnet.Socket
Transformboth, output derived from inputzlib.createGzip()

Backpressure

When a writable stream's buffer passes its highWaterMark (16 KB by default for byte streams, 16 objects in object mode), write() returns false. The producer should pause until the 'drain' event fires.

Use pipeline, not pipe

stream.pipeline() forwards errors and destroys every stream when one fails. Plain .pipe() does not, which leaks file handles.

const { pipeline } = require('node:stream/promises');
const fs = require('node:fs');
const zlib = require('node:zlib');

await pipeline(
  fs.createReadStream('access.log'),
  zlib.createGzip(),
  fs.createWriteStream('access.log.gz')
);
