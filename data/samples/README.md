# Sample corpus

Thirteen small, one-page files, one per format the ingestion pipeline must handle.
Each covers a different Node.js topic, so a retrieval test can check that the
right file answered.

Text files are written by hand. The binary ones (07–13) are generated by
`scripts/make_samples.py`. Re-run it to recreate them:

```bash
.venv/Scripts/python scripts/make_samples.py
```

| # | File | Format | Parser route | What it tests |
|---|---|---|---|---|
| 01 | `01-event-loop.md` | Markdown | `web_markup` | Heading-aware chunking, code fences |
| 02 | `02-streams.html` | HTML | `web_markup` | Nav/footer boilerplate removal, HTML table |
| 03 | `03-npm-packages.csv` | CSV | `tabular` | Row groups with repeated header |
| 04 | `04-error-codes.json` | JSON | `code_json` | Nested JSON splitting, exact-token (BM25) search |
| 05 | `05-express-server.js` | JavaScript | `code_json` | Language-aware code splitting |
| 06 | `06-security-checklist.txt` | Plain text | `fallback` | Unstructured plain text |
| 07 | `07-incident-email.eml` | Email + attachment | `email` | Headers as metadata, attachment recursion |
| 08 | `08-modules-guide.pdf` | PDF, text layer | `pdf_text` | Docling layout, table extraction |
| 09 | `09-buffers-handwritten-scan.pdf` | PDF, **no text layer** | `ocr_vision` | Handwriting OCR via vision model |
| 10 | `10-cluster-whiteboard.png` | Image | `ocr_vision` | Diagram and whiteboard text from an image |
| 11 | `11-error-handling.docx` | Word | `office` | Headings, bullet lists, table |
| 12 | `12-async-patterns.pptx` | PowerPoint | `office` | Slide text and speaker notes |
| 13 | `13-lts-schedule.xlsx` | Excel, 2 sheets | `tabular` | Multiple sheets, title row above the header |

## Test questions (seed for the eval set)

Each question can only be answered correctly from one file.

| # | Question | Expected answer contains |
|---|---|---|
| 01 | How many threads does the libuv thread pool have by default? | 4, `UV_THREADPOOL_SIZE` |
| 02 | Why should I use `stream.pipeline()` instead of `.pipe()`? | forwards errors, destroys streams |
| 03 | Which package is suggested as an alternative to bcrypt? | argon2 |
| 04 | What does `EMFILE` mean and how do I fix it? | too many open files, `stream.pipeline()` |
| 05 | How does the sample Express server handle SIGTERM? | `server.close()`, force exit after 10 s |
| 06 | How often should API keys be rotated? | every 90 days |
| 07 | What caused the order-service memory leak? | `.on('message')` per request, listener never removed |
| 07b | What is the time to mitigate in the postmortem? (attachment only) | 40 minutes |
| 08 | How do I get `__dirname` in an ES module? | `import.meta.dirname` |
| 09 | What does `Buffer.byteLength('héllo')` return? (handwritten) | 6 |
| 10 | Which PM2 command starts one worker per CPU? (image only) | `pm2 start app.js -i max` |
| 11 | Which HTTP status should a duplicate unique value return? | 409 Conflict |
| 12 | What should I use instead of `await` inside a for loop? (speaker notes) | `Promise.all`, p-limit |
| 13 | When does Node.js 22 reach end of life? | 2027-04-30 |

The LTS dates in file 13 reflect the Node.js release schedule as of 2026.
Check them against nodejs.org before using them outside tests.
